## 文書の優先順位

判断が食い違う場合は、次の順で確認する。

1. ユビキタス言語と画面仕様
2. このディレクトリの設計・規約
3. 現在の実装

現在の実装は移行途中のため、必ずしも本ガイドに準拠していない。差異は新規開発や関連箇所の変更時に段階的に解消し、資料と実装のどちらを変更した場合も相互に整合させる。
